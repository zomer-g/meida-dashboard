# חיבור כלי AI לדשבורד (MCP)

הדשבורד חושף שרת **MCP** מרוחק: אפשר לחבר אותו ל-Claude (או לכל כלי שתומך ב-MCP), לשאול שאלות בשפה חופשית על בקשות המידע, הרשויות, העתירות והפרסומים — והתשובות מגיעות מהנתונים האמיתיים של הדשבורד.

שתי מגבלות שבנויות לתוך השרת:

1. **קריאה בלבד.** אין ולו כלי אחד שכותב, מוחק או משנה. כל כלי מריץ אותן שאילתות שמייצרות את המסכים.
2. **ההרשאות של המשתמש, לא יותר.** הכלי פועל בשמו של אדם מסוים: אותו תפקיד, אותו סוג משתמש ואותם עמודים מותרים כמו בממשק. עיתונאי שמחבר את Claude יקבל רק את הכלים של העמודים שמותרים לו; הוא לא יראה רשימת בקשות, עתירות או כספים.

---

## למנהלי המערכת: הפעלה

1. **מגדירים מפתח חתימה.** בקונסולת xhostd → האפליקציה → Environment, מוסיפים `MCP_JWT_SECRET` כ-**Secret**, באורך 32 תווים ומעלה:

```bash
openssl rand -hex 32
```

2. **Redeploy.** בלי המשתנה הזה כל מסלולי ה-MCP מחזירים 503 — כלומר התכונה כבויה.
3. **ניהול → MCP** מציג את כתובת החיבור, את הכלים, את מי שהתחבר ואת הקריאות האחרונות.

אין צורך בהגדרה ב-Google Cloud: ההתחברות עוברת ב-SSO של xhostd, בדיוק כמו הכניסה לדשבורד.

## למשתמשים: חיבור Claude

1. ב-Claude: **Settings → Connectors → Add custom connector**.
2. מדביקים את הכתובת:

```
https://meida-dashboard-zomerg.xhostd.app/mcp
```

3. נפתח חלון התחברות — מתחברים עם **אותו חשבון Google** שבו נכנסים לדשבורד.
4. מופיע מסך אישור שמפרט מה הכלי יוכל לראות (העמודים המותרים לכם, קריאה בלבד). לוחצים **אישור החיבור**.
5. זהו. אפשר לשאול, למשל:
   - "כמה בקשות הגשנו למשרד הבריאות ב-2025, וכמה נענו במועד?"
   - "אילו רשויות הכי גרועות בעמידה במועדים, עם לפחות 20 בקשות?"
   - "כמה פרסומים יצאו מהבקשות שלנו השנה, ובאילו גופי תקשורת?"

מי שאינו משתמש מורשה בדשבורד יקבל הודעה שאין לו גישה. אם הגישה שלכם בדשבורד משתנה — המשתמש הושבת, סוג המשתמש שונה, עמוד נוסף או הוסר — זה חל על ה-MCP מיד, בלי לחבר מחדש.

## הכלים

| כלי | מה הוא מחזיר | מותנה בעמוד |
|---|---|---|
| `dashboard_info` | מצב הנתונים וההרשאות שלך | — |
| `list_filter_options` | ערכי סינון תקפים (ארגונים, תחומים, גופי תקשורת…) | — |
| `media_report` | סיכום הפרסומים ופילוח לפי גוף תקשורת, קטגוריה ורשות | דוח תקשורת |
| `media_over_time` | פרסומים לפי יום, מפוצלים לסדרות | דוח תקשורת |
| `publications_list` | הפרסומים עצמם, עם קישורים | דוח תקשורת |
| `authority_metrics` | עמידה במועדים, שלמות המענה והפורמט, לפי רשות / סוג / תחום / שנה | רשויות |
| `refusal_grounds` | התפלגות נימוקי הסירוב | רשויות |
| `requests_over_time` | בקשות שהוגשו לפי יום | ציר זמן |
| `authority_ranking` | הדירוג המשוקלל של הרשויות | דירוג רשויות |
| `requests_search` | בקשות בודדות, כולל חיפוש טקסט | רשימת בקשות |
| `petitions_list` | העתירות, תוצאותיהן והוצאות המשפט | עתירות |
| `activity_summary` | סיכום פעילות ופרויקטים | פעילות התנועה |
| `site_traffic` | תנועה באתר ודיוורים | אתר ודיוור |

לכל הכלים אותם פרמטרי סינון כמו בממשק: `range` (או `from`/`to`), `org`, `type`, `topic`, `owner`, `project`, `status`, `entity`, `petition`, ובכלים של התקשורת גם `outlet` ו-`category`.

## אבטחה — איך זה עובד

- **OAuth 2.1 עם PKCE.** הכלי נרשם לבד (Dynamic Client Registration), ואז שולח את המשתמש להתחברות. אסימון ניתן רק אחרי שאדם מחובר לחץ "אישור".
- **כתובת החזרה נבדקת** מול מה שהלקוח רשם, כך שקוד הרשאה לא יכול להישלח לאתר אחר.
- **אסימון גישה לשעה**, אסימון רענון ל-30 יום, שניהם חתומים ב-`MCP_JWT_SECRET`.
- **כל קריאה נבדקת מחדש מול בסיס הנתונים:** אם המשתמש הושבת, שונו הרשאותיו או שאדמין ניתק אותו — הגישה נפסקת מיד.
- **ניתוק:** ניהול → MCP → "ניתוק החיבורים" לאותו משתמש (מבטל את כל האסימונים שלו), או הסרת הלקוח. החלפת `MCP_JWT_SECRET` מנתקת את כולם.
- **תיעוד:** כל קריאה נרשמת (מי, איזה כלי, כמה שורות, כמה זמן) ונשמרת 90 יום; האישור עצמו נרשם גם ביומן הפעילות.
- **הגבלת קצב:** 120 קריאות לדקה למשתמש, 20 לדקה למסלולי ההתחברות.

## בדיקה מהירה אחרי פריסה

```bash
curl -s https://meida-dashboard-zomerg.xhostd.app/.well-known/oauth-protected-resource/mcp
curl -s -i -X POST https://meida-dashboard-zomerg.xhostd.app/mcp -H "Content-Type: application/json" -d '{}' | grep -i www-authenticate
```

הראשון מחזיר JSON עם `resource` ו-`authorization_servers`; השני מחזיר 401 עם כותרת `WWW-Authenticate` שמפנה למטא-דאטה. אלה שני הדברים שלקוח MCP צריך כדי להתחיל.

לבדיקה מלאה בלי Claude: `npx @modelcontextprotocol/inspector`, Transport = Streamable HTTP, URL = כתובת החיבור.
